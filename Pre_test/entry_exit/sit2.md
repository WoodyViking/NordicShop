
## Systemtest

| Entry Criteria | Obligatorisk/Önskevärt |
|---|---|
| Inga kritiska eller affärsblockerande defekter från tidigare testnivå | Obligatorisk |
| Systemtestmiljön är deployad. | Obligatorisk |
| Testdata för huvudflöden är redo. | Obligatorisk |
| Teststrategi och testplan är godkänd. | Önskevärt |
| All öppna defekter från SIT är listade så att kända fel inte rapporteras igen. | Önskevärt |
| Testdata kan återställas till utgångsläget på en dag. | Önskevärt |

| Exit Criteria | Obligatorisk/Önskevärt |
| Kritiska testfall är passerade | Obligatorisk. |
| Behörighetstest har genomförts och passerat. | Obligatorisk |
| Betalingsflöden är testade mot leverantörens testmiljö och kritiska testfall passerade. | Obligatorisk |
| Alla mindre defekter har beslutad hantering som är godkänd av PO. | Önskevärt |
| Inga nya större defekter har hittats dem senaste 3 testdagarna. | Önskevärt |
| Dokumentation för testresultat, testfallsstatus och defektlista är uppdaterade. | Önskevärt |
